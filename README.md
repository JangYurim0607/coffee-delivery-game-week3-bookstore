# 🪶 똑딱이의 원고 대작전 (Week3 · 프롬프트 구조화 실습)

커피 배달 게임을 **서점 주인 딱따구리 '똑딱이'가 마을 작가들에게 원고를 받아 오는 게임**으로 바꾼 결과물입니다.
`index.html` 하나로 브라우저에서 실행되며, 설치·서버·API 키가 필요 없습니다.

## 실행

`index.html`을 브라우저(Chrome, Edge, Safari)로 열고 **시작 / 계속**을 누릅니다.

## 조작

| 하고 싶은 일 | 조작 |
|---|---|
| 시작·계속 / 멈추기 / 처음으로 | 화면 아래 버튼 |
| 이동 | 방향키 또는 W / A / S / D, 화면 아래 방향 버튼 |
| 문 두드리기·재촉하기 | 클릭 연타 또는 Space |
| 음료 구매 | 카페 근처에서 1~3 키 |

## 게임 규칙

- 월~금, 하루는 실제 약 2분 30초이며 시계는 15분 단위로 넘어갑니다. 달 모양은 매일 바뀝니다.
- 서점 앞에서 할당량을 확인하면 왼쪽 위에 업무일지가 뜹니다.
- 걷기와 재촉은 에너지를 쓰고, 카페 음료(사과 < 석류 < 스타프루트)로 채웁니다. 모든 거래는 씨앗으로 합니다.
- 작가 집에서 문을 두드리고, 내기 미니게임이나 재촉으로 원고를 받습니다.
- 숲에서 몇 주 보낸 뒤에는 물총새 '총총이'가 되어 바다 마을을 다녀옵니다.

## 만든 방식

같은 커피 배달 게임에서 출발해, 프롬프트를 구조화하지 않은 버전(A)과 구조화한 버전(B)을 비교했습니다. 이 저장소는 구조화한 B입니다.
기록은 `WORKSHEET.md`에 있습니다. 테스트는 `node tests/game.test.cjs`로 실행합니다.
